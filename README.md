# Crystal Clear Window Cleaning 🪟

**Crystal Clear Window Cleaning** is a professional window cleaning company serving the Treasure Valley, Idaho — including Boise, Meridian, Nampa, Caldwell, Eagle, and surrounding areas.

## About This Site

This is a fully static, mobile-responsive marketing website built with:

- **Vanilla HTML/CSS/JS** — no framework dependencies, lightning fast
- **AI-generated video content** via [RunwayML Gen 4.5](https://runwayml.com) — photorealistic window cleaning footage
- **Hosted on Cloudflare Pages** — global CDN, zero cost, instant deploys
- **Google Fonts** — Inter + Playfair Display

## Placeholder Replacements

Search for these placeholders and fill in real business info before going live:

| Placeholder | Replace With |
|---|---|
| `[PHONE_NUMBER]` | Business phone, e.g. `(208) 555-1234` |
| `[EMAIL_ADDRESS]` | Business email |
| `[BUSINESS_HOURS]` | e.g. `Mon–Sat 7am–6pm` |
| `[LICENSE_NUMBER]` | Idaho contractor license number |
| `[PRICE]` | Starting prices for each tier |
| `[FACEBOOK_URL]` | Facebook business page URL |
| `[INSTAGRAM_URL]` | Instagram profile URL |
| `[GOOGLE_BUSINESS_URL]` | Google Business listing URL |

